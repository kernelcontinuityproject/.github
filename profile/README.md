# Kernel Continuity Project (KCP)

> **DISCLAIMER**
>
> KCP IS NOT AFFILIATED WITH THE LINUX CIVIL INFRASTRUCTURE PLATFORM (CIP).
> Although KCP may use code originating from CIP, the two projects are entirely independent.

## What is KCP?

The Kernel Continuity Project (KCP) is a Linux kernel project focused on providing patches, fixes, and backports to Linux kernels, primarily targeting Android devices.

## Where can I find supported devices?

See the [kcp-ci releases](https://github.com/kernelcontinuityproject/kcp-ci/releases).
